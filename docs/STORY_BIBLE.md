# 大楼没有下班 · Story implementation ledger

## Canon

Eli 是活着的成年维修兼保洁员，不是鬼，也不是做梦。十二年前 Gary 返回火场手动释放错误关闭的消防门，让 Eli 和其他人撤离。公开名单误把 Gary 写成已撤离，内部交班簿仍写在岗。日相位为事故前 17:59，夜相位为事故后 18:00。留班者来自未完成交班，不是 Gary。应急灯保存已完成工作，并让 Eli 重新聚合。

情感落点不是消灭遇难者，而是承认被遗漏的人并给最后一个人留门。

## 已进入运行版本

`dist/story.js`：中英文序章、三章任务文本、六条证据、普通结局和完整结局。替换原先无铺垫的诅咒/有人跟回家结局。`dist/simulation.js` 管理任务、证据、补正记录与应急灯标志。E 交互有短动作，完成任务永久保存。J 日志可回看证据与完成任务。

- 第一章：阀门、门内“别锁门”、错误撤离报告与 Gary 的值班灯。
- 第二章：十二年前便条、矛盾记录、手动消防联锁、饭盒放置文本。
- 第三章：浇水是完成承诺，疏散图与独立出口灯电路。
